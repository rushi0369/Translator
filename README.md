# 🌐 Translator

A responsive, lightweight language translator web app built with **vanilla HTML, CSS, and JavaScript**.

Translate text between languages using a simple, clean, and user-friendly interface.

## 🚀 Live Demo

🔗 **[Try Translator Live](https://transvibe.netlify.app)**

## 📌 GitHub Repository

🔗 [View Source Code on GitHub](https://github.com/rushi0369/Translator)

## ✨ Features

- 🌍 **Language Translation** — Translate text between supported languages.
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile devices.
- 🎨 **Simple UI** — Clean layout with an easy-to-use interface.
- ⚡ **Lightweight** — Built using vanilla HTML, CSS, and JavaScript.
- 🗣️ **Indian Languages** — Designed for translation involving Indian languages, depending on the configured translation service.
- 🔄 **Language Selection** — Select source and target languages.
- ✍️ **Text Input** — Enter the text you want to translate.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Application logic and user interactions

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rushi0369/Translator.git
```

### 2. Navigate to the project folder

```bash
cd Translator
```

### 3. Run the application

Open `index.html` in your web browser, or use the Live Server extension in Visual Studio Code.

No build tools are required for a basic vanilla HTML, CSS, and JavaScript project.

## ⚙️ Translation Service

The application can use a translation API to process text between supported languages.

If your project uses an external translation API, make sure the API is configured correctly and follow its authentication and usage requirements.

The goal of this project is to build a lightweight and accessible translation website that helps users communicate across language barriers through a simple web interface.
